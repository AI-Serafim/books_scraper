# Books Scraper

## Описание
Этот проект представляет собой скрипт для сбора данных о книгах с сайта [Books to Scrape](http://books.toscrape.com/). Он извлекает информацию о каждой книге, включая название, жанр, цены, наличие, рейтинг, описание, уникальный код (UPC), тип продукта, количество отзывов и ссылку на изображение обложки.

## Цель
Цель проекта — автоматизировать процесс сбора информации о книгах и сохранить её в структурированном виде (JSON) для дальнейшего анализа или использования.
